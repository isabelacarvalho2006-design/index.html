# ONG Esperança

## 📌 Descrição do Projeto

O projeto ONG Esperança consiste em um site desenvolvido para apresentar
a organização, seus projetos, eventos e possibilitar o cadastro de
pessoas interessadas em participar como voluntárias.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## 📂 Estrutura do Projeto

- `index.html` - Página principal
- `eventos.html` - Página de eventos
- `cadastro.html` - Formulário de cadastro
- `contato.html` - Página de contato
- `style.css` - Estilos e layout
- `script.js` - Funcionalidades JavaScript
- `README.md` - Documentação do projeto

## 💻 Pré-requisitos

Para executar o projeto é necessário ter:

- Um navegador atualizado
- Visual Studio Code (opcional)
- Git instalado (para controle de versão)

## ⚙️ Instalação Local

1. Clone o repositório:
   
   `https://github.com/isabelacarvalho2006-design/index.html`

2. Entre na pasta do projeto.

3. Abra a pasta no Visual Studio Code.

4. Abra o arquivo `index.html` no navegador.

O projeto não possui dependências externas, portanto não é necessário
executar comandos como `npm install`.

## ▶️ Execução

Após abrir o arquivo `index.html`, o site poderá ser acessado pelo
navegador. As demais páginas podem ser acessadas através do menu.

## 🔀 Versionamento

O projeto utiliza Git para controle de versão e Conventional Commits
para padronização das mensagens.

Exemplos:

- `feat:` para novas funcionalidades
- `style:` para alterações visuais
- `fix:` para correção de erros

Também foi adotado o Versionamento Semântico (SemVer):

`MAJOR.MINOR.PATCH`

A primeira versão estável do projeto é identificada pela tag:

`v1.0.0`
